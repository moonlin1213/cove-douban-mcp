# Security policy

Security reports are welcome through the repository's private GitHub Security
Advisory feature.

Please include:

- affected version and operating system;
- Python, Node.js, and OpenCLI versions;
- minimal reproduction using synthetic data where possible;
- expected and actual security boundary;
- whether local HTTP, export, setup, or an adapter is involved.

Do not include passwords, cookies, access tokens, private account pages,
browser profiles, real result bodies, or unredacted traces.

Supported security updates target the latest minor release. Maintainers will
acknowledge a complete report when available, assess severity, prepare a fix
and regression test, and coordinate disclosure. Please avoid public
disclosure until a fix or mitigation is ready.
